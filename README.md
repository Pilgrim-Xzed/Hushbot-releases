# Hush bot releases

Signed, notarized builds of Hush bot for macOS.

**[Download the latest release](https://github.com/Pilgrim-Xzed/Hushbot-releases/releases/latest)**: macOS 13 or later, Apple silicon and Intel.

Every release is signed with a Developer ID, notarized by Apple, and lists the SHA-256 of its DMG.
